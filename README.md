# QuickQR

A lightweight QR code generator built with Next.js, TypeScript and the `qrcode` package.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Push this folder to GitHub.
2. Import the repository into Vercel.
3. Keep the default Next.js settings.
4. Deploy.

No environment variables or database are required.

## Features

- Generate QR codes instantly
- URL/text support
- Size selection
- QR/background color selection
- Download PNG
- Copy QR image
- Fully client-side
- Responsive UI
